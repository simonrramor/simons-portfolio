# Source artwork

These original image exports are preserved for future editing. They are not used
by the website and live outside `public/` so Next.js does not copy them into every
static deployment.

- `images/originals/`: original project artwork exports.
- `images/iphone-fold/`: full-size edited iPhone Fold artwork. The website uses the
  existing `public/images/iphone-fold/*-display.webp` exports.

Keep production-ready images in `public/` and source artwork here. Moving these
files does not change any displayed image or its quality.
